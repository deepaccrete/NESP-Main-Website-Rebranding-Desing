Access

Three ways in

1 · DownloadEach layer as a shapefile, GeoJSON, CSV or Excel file from the catalogue above or the portal. Guide: how to download geodata.
2 · Connect QGISAdd a WMS or WFS connection with https://data.nigeriase4all.gov.ng/geoserver/ows. Guide: how to use WMS/WFS.
3 · Query from codeRequest GeoJSON directly, for example all mini-grids: WFS GetFeature.

What to watch for in the data

  • Installed substations (458 points) and thermal and hydro plants are each listed twice in the source layers; de-duplicate by name before counting.
  • The settlement layer's recorded distance to grid pre-dates recent MV mapping. For surveyed communities we recalculated it against distribution_line_mv: the median is 9.2 km to the nearest MV line.
  • The mini-grid layer holds 66 sites and does not yet include every programme mini-grid.
  • Field-survey records date from 2019 to 2026; new communities are still being added.
  • Dataset licences and update dates are not yet set on the portal (all layers show the same re-publish date).
